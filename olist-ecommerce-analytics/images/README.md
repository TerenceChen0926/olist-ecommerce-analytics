# Dashboard screenshots

The three report pages are completed in the Power BI snapshot, but the original
clipboard PNG files were temporary and are no longer available on disk.
Export or save fresh screenshots before adding the following image files:

| Page | Expected image |
|---|---|
| Executive Overview | `executive-overview.png` |
| Logistics Analysis | `logistics-analysis.png` |
| Customer Experience | `customer-experience.png` |

Capture only the report canvas with Year and Customer State set to All.
Use the same display scale for the three screenshots.

Once the images exist in this folder, add them to the root README with relative
Markdown paths, for example:

```markdown
![Executive Overview](images/executive-overview.png)
![Logistics Analysis](images/logistics-analysis.png)
![Customer Experience](images/customer-experience.png)
```
